# Mindustry 中文开发指南（Cursor 版）

本仓库导入自开源游戏 [Mindustry](https://github.com/Anuken/Mindustry)，保留了上游完整的 git 历史。这份指南说明怎样在本地用 Cursor 打开、构建、运行和修改它。

## 1. 环境准备

| 需要 | 说明 |
|---|---|
| JDK 17 | **必须是 17**，21 等其他版本会构建失败。推荐 [Temurin 17](https://adoptium.net/temurin/releases/?version=17)。 |
| Git | 克隆本仓库和 Arc。 |
| Cursor | 打开后按提示安装推荐扩展（Java Extension Pack、Gradle for Java），配置在 `.vscode/extensions.json`。 |
| Android SDK（可选） | 只有打安卓包时需要，见第 4 节。 |

### 克隆代码

Mindustry 依赖作者自己的引擎库 Arc。把 Arc 克隆到**和本仓库同一层的目录**，Gradle 会自动使用本地 Arc，比从 jitpack 下载稳定得多：

```bash
mkdir mindustry-dev && cd mindustry-dev
git clone https://github.com/jukes-oss/biggame.git
git clone --depth=1 https://github.com/Anuken/Arc.git
# 目录结构：mindustry-dev/biggame 和 mindustry-dev/Arc
```

> Arc 必须叫 `Arc` 并且和 `biggame` 同级，路径写死在 `settings.gradle` 里。

### 在 Cursor 中打开

1. 用 Cursor 打开 `biggame` 文件夹。
2. 如果电脑上装了多个 JDK，在设置里把 `java.jdt.ls.java.home` 或 Gradle 使用的 JDK 指向 JDK 17。
3. 等待 Gradle 同步完成（第一次会下载依赖，需要几分钟）。

## 2. 常用命令

在 `biggame` 目录下执行（Windows 把 `./gradlew` 换成 `gradlew`）：

| 做什么 | 命令 | 产物 |
|---|---|---|
| 直接运行 PC 版 | `./gradlew desktop:run` | |
| 打包 PC 版 | `./gradlew desktop:dist` | `desktop/build/libs/Mindustry.jar` |
| 打包服务器 | `./gradlew server:dist` | `server/build/libs/server-release.jar` |
| 运行测试 | `./gradlew tests:test` | |
| 重新打包贴图 | `./gradlew tools:pack` | 改了 `core/assets-raw` 里的图片后执行 |

打包好的游戏用 `java -jar desktop/build/libs/Mindustry.jar` 启动。

`gradle.properties` 默认给 Gradle 分配最多 8 GB 内存（`-Xmx8192m`）。电脑内存小于 16 GB 时，可以改成 `-Xmx4g`。

## 3. 代码结构速查

| 目录 | 内容 |
|---|---|
| `core/src/mindustry/content/` | 所有游戏内容：`Blocks`、`Items`、`UnitTypes`、`Bullets`、`Planets`、科技树 |
| `core/src/mindustry/world/blocks/` | 各类方块的行为实现 |
| `core/src/mindustry/entities/comp/` | 实体组件，构建时合成为实体类 |
| `core/src/mindustry/type/` | `UnitType`、`Item`、`Weapon` 等类型 |
| `core/src/mindustry/ui/` | 界面和对话框 |
| `core/src/mindustry/logic/` | 游戏内的逻辑处理器（mlog） |
| `core/assets/bundles/` | 多语言文本，简体中文在 `bundle_zh_CN.properties` |
| `core/assets-raw/sprites/` | 原始贴图 |
| `desktop/`、`android/`、`ios/`、`server/` | 各平台启动器 |

**`mindustry.gen` 包是构建时自动生成的**（`Call`、`Unit`、`Building`、`Sounds`、`Icon` 等），仓库里找不到它的源码属于正常现象。先构建一次，IDE 就能识别这些类。不要手动编辑生成的文件。

## 4. 打安卓包

1. 下载 Android SDK 的 [Command line tools](https://developer.android.com/studio#command-tools)（不需要 Android Studio）。
2. 解压后在 `cmdline-tools` 里新建 `latest` 文件夹，把原来的内容移进去。
3. 运行 `sdkmanager --licenses` 接受许可。
4. 设置环境变量 `ANDROID_HOME` 指向 SDK 目录。
5. 执行 `./gradlew android:assembleDebug`，APK 在 `android/build/outputs/apk`。

## 5. 用 Cursor 开发

仓库已经为 Cursor 做了这些配置：

- `.cursor/rules/00-project.mdc`：项目结构、生成代码、构建命令，每次对话都会带上。
- `.cursor/rules/10-java-style.mdc`：编辑 Java 文件时生效，包含上游的代码风格和安卓/iOS 兼容限制（不能用 `java.util.stream` 等）。
- `.cursor/rules/20-content.mdc`：编辑游戏内容时生效，说明新增方块/单位要同时改哪些地方。
- `.cursorignore`：不索引构建产物、图片音频等二进制资源和其他语言的翻译，让 AI 检索更准。

给 Cursor 提需求时的建议：

- 说清楚改哪类内容，比如“在 `Blocks.java` 里仿照 `duo` 新增一个炮塔”。
- 让它改完后执行 `./gradlew desktop:dist` 确认能编译，再用 `./gradlew desktop:run` 实际试玩。
- 新增内容记得让它同时补 `bundle.properties` / `bundle_zh_CN.properties` 的名称描述和科技树。

## 6. 许可证注意事项

- Mindustry 采用 **GPL-3.0**（见 `LICENSE`）。基于它修改后的版本如果对外发布（包括上架、分发安装包），必须同样以 GPL-3.0 开源，并保留原作者署名。
- 来源说明见 `UPSTREAM.md`。
- 上游项目**不接受 AI 生成的 PR**（见 `CONTRIBUTING.md` 的 AI Policy）。在本仓库里用 Cursor 开发没有问题，但如果以后想把改动贡献回上游，需要遵守它的规定。
